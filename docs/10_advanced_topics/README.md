# Chapter 10 — 発展的な構造

ここでは「SVD で線形代数のすべてを説明できるわけではない」部分へ進みます。

## Jordan 標準形

固有ベクトルが十分にない行列でも、一般化固有ベクトルを使えば Jordan form まで単純化できます。これは線形作用素の代数的構造を調べる道具です。

## 行列関数と時間発展

\[
\dot x=Ax
\]

の解

\[
x(t)=e^{At}x(0)
\]

では、固有値が時間発展の成長・減衰を支配します。

ここでは SVD より固有値の方が自然です。SVD は一回の写像の伸縮を理解するのに優れ、固有値は同じ写像を繰り返すダイナミクスを理解するのに優れます。

## 双対空間

ベクトルそのものと、そのベクトルをスカラーへ写す線形汎関数を区別します。Euclid 空間では内積が両者を自然に対応させるため見えにくい概念ですが、微分幾何やテンソルでは重要です。

## 到達基準
