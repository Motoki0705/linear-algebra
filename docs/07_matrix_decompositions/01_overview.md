# 行列分解の全体像

行列分解の目的は、複雑な線形写像を、意味の分かる単純な写像の積へ分けることです。

代表例は

- LU: 消去法の構造を分離する
- QR: 直交基底と座標係数へ分離する
- 固有値分解: 固有方向と伸縮率へ分離する
- SVD: 入力側の直交基底・伸縮・出力側の直交基底へ分離する

です。

## 分解は「同じものを別の座標で見る」技術

行列 `A` を直接眺めても、その本質が見えにくいことがあります。分解は、`A` がどの方向に何をしているのかを露出させます。

例えば SVD

\[
A=U\Sigma V^\top
\]

は、

1. `V^T` で入力を右特異ベクトル基底へ変換する
2. `Σ` で各軸を特異値だけ伸縮する
3. `U` で出力空間へ向きを合わせる

という3段階です。

## 分解を選ぶ基準

「最良の分解」が一つあるわけではありません。

- 方程式を何度も解く → LU
- 最小二乗を安定に解く → QR
- 正方行列の反復挙動を見る → 固有値分解
- ランク・条件数・擬似逆・低ランク近似を統一して見る → SVD

と目的に応じて選びます。
