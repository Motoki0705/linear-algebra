# Chapter 07 — 行列分解

この章は前半の概念が合流する場所です。

## なぜ分解するのか

一つの大きな操作 `A` を、そのまま理解するより

\[
A=A_1A_2\cdots A_k
\]

と意味の分かる操作に分ける方が理解しやすく、計算にも有利です。

## LU / QR / EVD / SVD の役割

### LU

Gauss 消去を保存した分解。主目的は連立方程式の効率的な解法です。

### QR

列空間を正規直交基底 `Q` と係数 `R` に分けます。最小二乗に強い分解です。

### EVD

同じ空間内の不変方向を探します。反復変換や力学系を理解するのに適します。

### SVD

\[
A=U\Sigma V^T
\]

任意の行列を、入力側の直交基底・純粋な伸縮・出力側の直交基底へ分けます。

## SVD を理解する核心

必ず次の式を言葉にしてください。

\[
Av_i=\sigma_i u_i.
\]

これは「入力方向 `v_i` を入れると、方向 `u_i` へ向かう長さ `σ_i` の出力になる」という意味です。

さらに

\[
A=\sum_i\sigma_i u_iv_i^T
\]

と書けば、行列は重要度順の rank-1 成分へ分解されます。

ここから低ランク近似が出ます。`σ_i=0` の方向は核になり、`1/σ_i` を使えば擬似逆が出ます。`σ_max/σ_min` を見れば条件数になります。
