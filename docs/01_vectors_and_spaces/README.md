# Chapter 01 — ベクトルと空間

この章の目的は、ベクトルを「数の並び」から解放することです。

## 中心となる考え

線形代数では、対象そのものよりも「その対象をどの方向の組合せとして表せるか」を考えます。

```text
ベクトル
 ↓
一次結合
 ↓
span（作れる範囲）
 ↓
一次独立（冗長でない方向）
 ↓
基底（必要十分な方向の集合）
 ↓
次元（独立な自由度の数）
```

この流れは別々の用語集ではありません。すべて「空間を最小限の独立な方向で記述する」という一つの問題に答えています。

## 最も重要な区別

**ベクトルと座標は別物です。**

同じ矢印でも、基底を変えれば座標は変わります。例えば通常の基底では `(1,1)` と表されるベクトルが、別の基底では `(√2,0)` と表されるかもしれません。

この事実を受け入れると、後の対角化や SVD の意味が見えます。それらは「線形変換が簡単に見える座標系を探す」方法だからです。

## 学習時に考える問い

- `span` はなぜ必ず部分空間になるのか。
- 一次従属なベクトルを基底から取り除いても span が変わらないのはなぜか。
- `R^1000` のデータでも本質的には10次元ということはあり得るか。
- 基底を変えても次元が変わらないのはなぜか。

## 典型的な誤解

「ベクトルの成分数 = 常に本質的な次元」ではありません。成分数は周囲の座標空間の次元であり、データ集合が張る部分空間の次元はもっと小さいことがあります。この差が rank や PCA の出発点です。

## 到達基準

章末では、基底を「空間を一意に座標化する最小の独立方向集合」と説明できることを目指してください。
