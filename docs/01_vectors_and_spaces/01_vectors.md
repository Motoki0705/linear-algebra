# ベクトル

ベクトルはしばしば「向きと大きさを持つ矢印」と説明されます。しかし線形代数では、より本質的に **加法とスカラー倍ができる対象** と考えます。

\[
x+y,\qquad \alpha x
\]

が同じ種類の対象として定義できることが重要です。

## 座標はベクトルそのものではない

\[
x=\begin{bmatrix}2\\3\end{bmatrix}
\]

という数の並びは、ある基底を選んだときの座標です。基底を変えれば同じ幾何学的ベクトルでも座標は変わります。

この区別は後の

- 基底変換
- 固有ベクトル
- PCA
- SVD

に直結します。

## ベクトルとして扱えるもの

ベクトルは数の列に限りません。

- 多項式
- 関数
- 画像
- 音声波形
- 行列

なども、加法とスカラー倍についてベクトル空間を作れます。

例えば画像を `m×n` 個の画素値として見れば、一枚の画像は `R^{mn}` のベクトルと考えられます。この視点が PCA や画像圧縮につながります。

## 理解チェック

「ベクトル」と「その座標」の違いを説明できますか。これを説明できることが、後の基底概念の出発点です。
