# Span

`v_1,...,v_k` のすべての一次結合の集合を

\[
\operatorname{span}\{v_1,\dots,v_k\}
\]

と書きます。

## 幾何学的意味

`R^3` で

- 1本の非零ベクトルの span は原点を通る直線
- 独立な2本の span は原点を通る平面
- 独立な3本の span は `R^3` 全体

になります。

ここで重要なのは、ベクトルの「本数」ではなく、独立な方向の数です。同じ方向のベクトルを何本追加しても span は広がりません。

## 連立方程式との接続

`Ax=b` が解を持つ条件は

\[
b\in\operatorname{span}\{a_1,\dots,a_n\}
\]

です。つまり `b` が `A` の列空間に存在することです。

この一文だけで、連立方程式の可解性を幾何学的に表現できます。
