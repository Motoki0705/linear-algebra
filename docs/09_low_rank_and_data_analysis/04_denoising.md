# SVD によるノイズ除去

観測行列を

\[
A=S+N
\]

とします。`S` が信号、`N` がノイズです。

信号が低ランク構造を持ち、ノイズが多数の方向へ分散しているなら、上位特異成分に信号が集まりやすくなります。

そこで

\[
A_k=\sum_{i=1}^k\sigma_i u_i v_i^\top
\]

として小さな特異成分を捨てます。

## 圧縮との違い

数式は画像圧縮と同じでも目的が違います。

- 圧縮: 少ないパラメータで表す
- ノイズ除去: 小さな成分をノイズとみなして除く

## 限界

小さい特異値が必ずノイズとは限りません。細かなテクスチャや弱い信号も小さい特異値に現れることがあります。

そのため `k` の選択は bias–variance trade-off を持ちます。小さすぎる `k` は信号を消し、大きすぎる `k` はノイズを残します。
