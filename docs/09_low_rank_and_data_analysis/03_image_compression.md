# SVD による画像圧縮

グレースケール画像を行列

\[
A\in\mathbb{R}^{m\times n}
\]

として扱います。

SVD

\[
A=U\Sigma V^\top
\]

の上位 `k` 成分だけを残すと

\[
A_k=U_k\Sigma_kV_k^\top
\]

です。

## なぜ圧縮になるのか

元画像は `mn` 個の値を持ちます。一方 rank-k 表現はおよそ

\[
k(m+n+1)
\]

個の値で表現できます。

`k` が十分小さければ大きな削減になります。

## なぜ画像が残るのか

自然画像では近接画素に強い相関があり、完全に独立な `mn` 個の自由度を持つわけではありません。そのため特異値が上位成分へ集中しやすくなります。

## 重要な注意

SVD 圧縮は JPEG そのものではありません。SVD は低ランク構造を利用する一般的な数学モデルであり、実用画像コーデックは量子化・周波数変換・エントロピー符号化なども利用します。
