# スペクトル定理

実対称行列 `A` は必ず

\[
\boxed{A=Q\Lambda Q^\top}
\]

と直交対角化できます。

ここで `Q` の列は正規直交固有ベクトルです。

## 幾何学

対称行列は、ある直交座標系を選べば、各軸を独立に伸縮するだけの変換になります。せん断のような「軸同士の混ざり」が適切な基底では消えます。

## SVD への橋

`A^TA` は対称半正定値なので

\[
A^\top A=V\Lambda V^\top
\]

と書けます。この固有値は非負で

\[
\sigma_i=\sqrt{\lambda_i}
\]

と置くことで特異値が得られます。

したがって SVD は、スペクトル定理を一般行列へ拡張したような位置づけでも理解できます。
