# Chapter 06 — 固有値と固有ベクトル

線形変換は通常ベクトルの方向を変えます。しかし、ごく特別な方向では向きを変えず倍率だけ変えます。

\[
Av=\lambda v
\]

この `v` が固有ベクトルです。

## 本質は「自然な座標軸を探す」こと

固有ベクトルを基底にできれば

\[
A=P\Lambda P^{-1}
\]

となり、複雑な変換が各座標の独立なスカラー倍へ変わります。

これは線形代数で繰り返される思想です。

> 対象に合った基底を選べば、複雑なものが単純に見える。

## 固有値が動力学を支配する理由

`A` を何度も作用すると

\[
A^kv_i=\lambda_i^kv_i
\]

なので、長期挙動は `|λ_i|` の大小で決まります。連続時間なら `e^{λ_it}` が現れます。

## 対称行列が特別な理由

一般行列では固有ベクトルが足りなかったり直交しなかったりします。実対称行列では必ず正規直交固有基底が存在します。

この非常に強い性質が、`A^TA` を使って SVD を構成できる理由です。

## 到達基準

固有値を単なる `det(A-λI)=0` の根ではなく、「変換に固有な不変方向の伸縮率」と説明できることを目指します。
