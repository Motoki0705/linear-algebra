# 条件数

可逆行列に対する2-ノルム条件数は

\[
\boxed{\kappa_2(A)=\|A\|_2\|A^{-1}\|_2=\frac{\sigma_{\max}}{\sigma_{\min}}}
\]

です。

## 幾何学的意味

`A` は単位球を楕円体へ写します。最長半径が `σ_max`、最短半径が `σ_min` です。

`σ_min` が非常に小さいと、ある方向がほとんど平らに潰れています。その出力から元の入力を復元するには `1/σ_min` 倍する必要があり、観測ノイズまで大きく増幅します。

## 条件が悪いとは

条件数が大きい問題は、アルゴリズムが悪い以前に「問題そのものが入力誤差に敏感」です。

数値線形代数では

- 問題の conditioning
- アルゴリズムの stability

を区別することが重要です。
