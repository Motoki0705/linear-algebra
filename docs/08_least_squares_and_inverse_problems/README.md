# Chapter 08 — 最小二乗と逆問題

現実のデータでは `Ax=b` が完全には成立しないことが普通です。観測ノイズ、モデル誤差、過剰な方程式があるからです。

## 「解く」から「最も近いものを探す」へ

\[
\min_x\|Ax-b\|^2
\]

という問題に切り替えます。

これは `b` を `Col(A)` へ直交射影することです。したがって最小二乗は、最適化の公式より前に幾何学として理解できます。

## 正規方程式の意味

\[
A^TAx=A^Tb
\]

は、残差 `r=b-Ax` に対して

\[
A^Tr=0
\]

すなわち「残差がすべての列方向に直交する」と言っているだけです。

## 逆問題の難しさ

SVD 座標で逆算すると

\[
x=A^+b=\sum_i\frac{u_i^Tb}{\sigma_i}v_i.
\]

小さい `σ_i` があると、その方向では観測誤差まで巨大化します。

この式は、なぜ悪条件問題で単純な逆算が危険かを直接示しています。

## 正則化という考え方

truncated SVD は小さすぎる特異値を捨てます。これは情報を減らす行為ですが、結果として推定が良くなることがあります。

「完全に逆にする」より「信頼できる方向だけ逆にする」方がよい場合がある、という逆問題の重要思想です。

## 到達基準

最小二乗、擬似逆、条件数、正則化を別々の公式としてではなく、SVD の各特異方向で何が起こるかとして説明してください。
