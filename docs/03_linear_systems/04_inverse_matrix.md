# 逆行列

正方行列 `A` に対して

\[
A^{-1}A=AA^{-1}=I
\]

を満たす行列を逆行列と呼びます。

## 逆行列が存在するとは何か

`A` が可逆であることは、線形写像が情報を一切失わないことを意味します。

同値な条件には

- `ker(A)={0}`
- `rank(A)=n`
- 列が一次独立
- `det(A)≠0`
- 0 が固有値でない
- 最小特異値が 0 でない

などがあります。

## 実務上の注意

`Ax=b` を解くために明示的に `A^{-1}` を計算する必要は通常ありません。LU や QR などの分解を用いる方が効率・数値安定性の面で優れています。
