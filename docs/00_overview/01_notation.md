# 記法

この教材では、ベクトルを小文字、行列を大文字で表します。

\[
x\in\mathbb{R}^n,\qquad A\in\mathbb{R}^{m\times n}
\]

`A` の第 `i` 行第 `j` 列を `a_{ij}` と書きます。

## 基本記号

- `x^T`: 転置
- `A^{-1}`: 逆行列
- `I`: 単位行列
- `0`: 零ベクトルまたは零行列
- `span{v_1,...,v_k}`: ベクトルの一次結合で生成される空間
- `ker(A)`: `Ax=0` を満たす入力の集合
- `Im(A)` / `Col(A)`: `A` の像・列空間
- `rank(A)`: 像の次元
- `||x||_2`: Euclid ノルム
- `<x,y>`: 内積

## 列ベクトルを基本とする

特に断らない限り、ベクトルは列ベクトルです。

\[
x=\begin{bmatrix}x_1\\x_2\\\vdots\\x_n\end{bmatrix}
\]

したがって `A∈R^{m×n}` と `x∈R^n` に対して

\[
Ax\in\mathbb{R}^m
\]

です。

## 「等しい」と「同型」を区別する

抽象的なベクトル空間 `V` と座標空間 `R^n` は、基底を選べば対応づけられますが、概念として同一ではありません。行列は「線形写像そのもの」ではなく、「基底を固定したときの線形写像の表現」です。

この区別は、基底変換や固有値分解を理解するときに重要になります。
