# 学習経路

## Stage 1: 空間を理解する

`01_vectors_and_spaces` では、ベクトルを矢印としてだけでなく、加法とスカラー倍ができる対象として捉えます。

到達目標は、`span`、一次独立、基底、次元を自分の言葉で説明できることです。

## Stage 2: 行列を写像として理解する

`02_matrices_and_linear_maps` では、行列積を計算規則ではなく写像の合成として捉えます。

特に

\[
\dim\ker A+\operatorname{rank}(A)=n
\]

が「入力の自由度が、消える方向と残る方向に分かれる」という意味を持つことを理解します。

## Stage 3: 方程式を空間として理解する

`Ax=b` は数値を求める問題であると同時に、`b` が列空間に入っているかを問う問題です。

Gauss 消去を「アルゴリズム」としてだけでなく、「解空間の構造を露出させる操作」として学びます。

## Stage 4: 幾何学を入れる

内積を導入すると、長さ・角度・直交・最短距離を定義できます。ここから射影と最小二乗が自然に出てきます。

## Stage 5: 線形変換の不変な方向を探す

固有値・固有ベクトルは

\[
Av=\lambda v
\]

を満たす特別な方向です。ここで「良い基底を選ぶと変換が単純になる」という考え方を身につけます。

## Stage 6: 分解する

LU、QR、固有値分解、SVD を比較します。特に SVD は一般の長方形行列にも使え、ランク・最小二乗・擬似逆・低ランク近似を統一します。

## 学習方法

各節で次の順序を守ることを推奨します。

1. 定義を読む。
2. 図形的・構造的な意味を言葉で説明する。
3. 数式を自力で導出する。
4. 小さな行列で手計算する。
5. 演習を解く。
6. NumPy で検算する。

計算だけ解けても、定義の意味を説明できなければ次に進まないのが理想です。
