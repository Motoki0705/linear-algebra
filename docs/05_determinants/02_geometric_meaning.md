# 行列式の幾何学的意味

単位正方形の辺ベクトル `e_1,e_2` を `A` で変換すると、辺は `Ae_1,Ae_2` になります。

これらが作る平行四辺形の面積は

\[
|\det A|
\]

です。

符号は向きを表します。負の行列式は鏡映を含むような向きの反転を意味します。

## 特異値との関係

正方行列の SVD

\[
A=U\Sigma V^\top
\]

を考えると、直交行列 `U,V` は体積の絶対値を変えません。したがって

\[
|\det A|=\prod_i\sigma_i
\]

です。

つまり行列式の絶対値は、各主軸方向の伸縮率である特異値の積です。この式は行列式と SVD の幾何学を直接結びつけます。
