# Chapter 02 — 行列と線形写像

この章では、行列を表計算のような数表ではなく **空間を変形する関数** として捉えます。

## 行列の三つの顔

`Ax` には同時に三つの意味があります。

1. 行ごとに見れば、各出力は入力との内積。
2. 列ごとに見れば、出力は列ベクトルの一次結合。
3. 全体として見れば、`R^n→R^m` の線形写像。

この三つを切り替えられることが線形代数の強さです。

## 核と像がなぜ重要か

線形写像を理解する最小限の問いは

- どの入力が消えるか → `ker(A)`
- どの出力に到達できるか → `Im(A)`

です。

この二つだけで、解の一意性、可逆性、情報損失をかなり説明できます。

例えば `z≠0` なのに `Az=0` なら

\[
A(x+z)=Ax
\]

です。つまり出力を見ても `x` と `x+z` を区別できません。核は単なる方程式 `Ax=0` の解集合ではなく、**観測で失われた自由度**です。

## rank-nullity の読み方

\[
\dim\ker A+\operatorname{rank}(A)=n
\]

を公式として暗記せず、入力の `n` 自由度が

- 出力まで伝わる自由度
- 途中で消える自由度

へ分かれる保存則のように読みます。

## 到達基準

行列を見たとき「この行列は何を入力として何を出力する写像か」「何次元を保存し、何次元を失うか」を考えられることが目標です。
