# 行列積

`AB` は単なる計算規則ではなく、**線形写像の合成** を表します。

`B:R^n→R^k`、`A:R^k→R^m` なら

\[
AB:R^n\to R^m
\]

であり、

\[
x\xrightarrow{B}Bx\xrightarrow{A}A(Bx)
\]

です。

したがって

\[
(AB)x=A(Bx)
\]

となります。

## なぜ一般に AB≠BA なのか

写像の順序を変えると結果が変わるからです。例えば「回転してから射影」と「射影してから回転」は通常同じ操作ではありません。

## SVD との接続

\[
A=U\Sigma V^\top
\]

は、`V^T`、`Σ`、`U` という3つの写像の合成です。この意味を理解するためにも、行列積を写像の合成として捉えることが重要です。
