# ランク

行列 `A` のランクは像の次元です。

\[
\operatorname{rank}(A)=\dim\operatorname{Im}(A)
\]

## 直感

ランクは「この線形変換が何次元分の独立な情報を出力へ運べるか」を表します。

例えば `R^3→R^3` の写像でも、すべての点を一つの平面へ潰すならランクは2です。一本の直線へ潰すならランクは1です。

## 同値な定義

ランクは

- 独立な列の最大本数
- 独立な行の最大本数
- pivot の数
- 非零特異値の数

のいずれでも求められます。

最後の見方から

\[
\operatorname{rank}(A)=\#\{\sigma_i>0\}
\]

となり、SVD と直接つながります。
