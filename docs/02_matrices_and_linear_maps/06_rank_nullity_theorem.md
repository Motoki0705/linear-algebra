# 次元定理（Rank–Nullity Theorem）

`A:R^n→R^m` に対して

\[
\boxed{\dim\ker A+\operatorname{rank}(A)=n}
\]

が成立します。

## 本質的な意味

入力空間の `n` 個の自由度は、

- 変換後に残る方向
- 変換によって消える方向

に完全に分配されます。

例えば `rank(A)=r` なら、独立な出力情報は `r` 次元で、失われる入力自由度は `n-r` 次元です。

## SVD で見る

\[
A=U\Sigma V^\top
\]

で非零特異値が `r` 個なら、`V` の最初の `r` 本は情報が出力へ伝わる方向、残り `n-r` 本は零空間方向です。

したがって次元定理は、SVD の幾何学ではほとんど目で見える形になります。
