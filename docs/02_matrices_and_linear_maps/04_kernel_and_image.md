# 核と像

線形写像 `A:R^n→R^m` に対して

\[
\ker A=\{x\mid Ax=0\}
\]

を核、

\[
\operatorname{Im}A=\{Ax\mid x\in\mathbb{R}^n\}
\]

を像と呼びます。

## 核の意味

核は変換によって完全に消えてしまう入力方向です。`x_1-x_2∈ker(A)` なら

\[
Ax_1=Ax_2
\]

なので、`A` はその二つの入力を区別できません。

## 像の意味

像は `A` によって到達できる出力全体です。行列の場合、像は列空間と同じです。

## 情報という視点

核が大きいほど入力情報が失われます。像の次元がランクです。SVD では零特異値に対応する右特異ベクトルが核を張ります。
