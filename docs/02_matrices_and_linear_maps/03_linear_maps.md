# 線形写像

写像 `T:V→W` が線形であるとは

\[
T(x+y)=T(x)+T(y),\qquad T(\alpha x)=\alpha T(x)
\]

を満たすことです。

まとめれば

\[
T(\alpha x+\beta y)=\alpha T(x)+\beta T(y)
\]

です。

## なぜこの条件が重要か

線形写像では、基底ベクトルがどこへ移るかだけ分かれば、すべてのベクトルの行き先が決まります。

\[
x=\sum_i c_i b_i
\]

なら

\[
T(x)=\sum_i c_iT(b_i)
\]

だからです。

これが行列で線形写像を有限個の数として記述できる理由です。

## 行列は基底依存

同じ `T` でも基底が変われば表現行列は変わります。しかし写像そのもののランクや固有値など、基底変換に対して本質的に保存される量があります。
