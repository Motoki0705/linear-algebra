# 演習 04 — 内積・直交・射影

## 1. 角度

`x=(1,1)^T`, `y=(1,0)^T` のなす角を求めてください。

## 2. 射影

`b=(3,2)^T` を `a=(1,1)^T` が張る直線へ直交射影してください。

## 3. 射影行列

単位ベクトル `q` に対し `P=qq^T` が `P^2=P` と `P^T=P` を満たすことを示してください。

## 4. Gram–Schmidt

`a_1=(1,1,0)^T`, `a_2=(1,0,1)^T` を正規直交化してください。

## 5. 最小二乗への橋

最小二乗解で残差 `r=b-Ax` が `Col(A)` に直交しなければならない理由を、最短距離の観点から説明してください。
