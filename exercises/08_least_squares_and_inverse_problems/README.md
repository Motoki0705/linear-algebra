# 演習 08 — 最小二乗と逆問題

## 1. 直線フィッティング

点 `(0,1),(1,2),(2,2)` に `y=ax+b` を最小二乗で当てはめるための `A,x,b` を構成し、正規方程式を解いてください。

## 2. 正規方程式

`||Ax-b||^2` を微分して `A^TAx=A^Tb` を導出してください。

## 3. 射影

full-column-rank `A` に対して

\[
P=A(A^TA)^{-1}A^T
\]

が列空間への直交射影であることを示してください。

## 4. 擬似逆

SVD から `A^+=VΣ^+U^T` を構成し、可逆正方行列の場合に `A^+=A^{-1}` となることを示してください。

## 5. 条件数

特異値が `10` と `10^{-4}` の行列の2-ノルム条件数を求め、その値が逆問題に何を意味するか説明してください。
