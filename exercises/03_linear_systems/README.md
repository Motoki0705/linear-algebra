# 演習 03 — 連立一次方程式

## 1. Gauss 消去

\[
\begin{cases}
x+2y-z=1\\
2x+4y+z=4\\
-x-2y+2z=1
\end{cases}
\]

を Gauss 消去で解いてください。

## 2. 解の存在

`Ax=b` が解を持つことと `b∈Col(A)` が同値であることを、行列積を列の一次結合として説明してください。

## 3. 解集合

`x_p` が `Ax=b` の一つの解であるとき、全解が `x_p+ker(A)` と書けることを証明してください。

## 4. 一意性

`Ax=b` の解が存在すると仮定します。解が一意であることと `ker(A)={0}` が同値であることを示してください。
