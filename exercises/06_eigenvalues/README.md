# 演習 06 — 固有値

## 1. 固有値計算

\[
A=\begin{bmatrix}2&1\\1&2\end{bmatrix}
\]

の固有値と正規化固有ベクトルを求めてください。

## 2. 対角化

上の `A` を `QΛQ^T` と書いてください。

## 3. 反復

初期ベクトルを固有ベクトル基底で `x_0=c_1v_1+c_2v_2` としたとき、`A^kx_0` を求め、`k→∞` の挙動を説明してください。

## 4. 対称行列

実対称行列の異なる固有値に属する固有ベクトルが直交することを証明してください。

## 5. SVD への橋

なぜ `A^TA` の固有値が非負になるのか説明してください。
