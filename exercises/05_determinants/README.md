# 演習 05 — 行列式

## 1. 計算と幾何

\[
A=\begin{bmatrix}2&1\\0&3\end{bmatrix}
\]

の行列式を求め、単位正方形の面積が何倍になるか説明してください。

## 2. 可逆性

`det(A)=0` なら `A` の列が一次従属になる理由を説明してください。

## 3. 積

`det(AB)=det(A)det(B)` を体積倍率という観点から説明してください。

## 4. SVD との接続

正方行列について

\[
|\det A|=\prod_i\sigma_i
\]

となる理由を `A=UΣV^T` から説明してください。

## 5. 深掘り

行列式が小さいことと、行列が数値的に不安定であることは同じですか。反例やスケール依存性を考えてください。
