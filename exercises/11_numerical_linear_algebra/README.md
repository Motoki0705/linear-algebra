# 演習 11 — 数値線形代数

## 1. conditioning

`A=diag(1,10^{-8})` の条件数を求め、幾何学的に説明してください。

## 2. 正規方程式

上の `A` に対して `κ(A^TA)` を求め、なぜ最小二乗で正規方程式が精度を悪化させ得るか説明してください。

## 3. stability

「問題が悪条件」と「アルゴリズムが不安定」の違いを例を使って説明してください。

## 4. iterative method

大規模疎行列に対して完全な逆行列を作らず、行列ベクトル積だけを使う利点を説明してください。

## 5. randomized SVD

上位 `k` 特異空間だけ必要な場合、完全 SVD を避けたい理由と randomized SVD の基本的発想を説明してください。
