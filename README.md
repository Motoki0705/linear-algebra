# Linear Algebra — 構造から理解する線形代数

このリポジトリは、線形代数を「公式を覚える科目」ではなく、**空間・線形写像・分解・近似という一つの体系**として理解するための教材です。

## 学習の中心となる問い

線形代数では、次の問いを繰り返し扱います。

1. どのようなベクトルを組み合わせると、どの空間を表現できるか。
2. 線形写像は空間をどのように変形するか。
3. その変形によって、何が保存され、何が失われるか。
4. 行列を適切な基底で見たとき、その本質はどこまで単純になるか。
5. 厳密な解が存在しない場合、最も自然な近似解をどう定義するか。
6. 固有値分解や SVD によって、線形変換の構造をどう読み解くか。

## 推奨学習順序

```text
ベクトル・ベクトル空間
        ↓
行列・線形写像
        ↓
連立一次方程式
        ↓
内積・直交・射影
        ↓
行列式
        ↓
固有値・固有ベクトル
        ↓
行列分解（LU / QR / EVD / SVD）
        ↓
最小二乗・擬似逆行列
        ↓
低ランク近似・PCA・画像圧縮・ノイズ除去
        ↓
数値線形代数・発展トピック
```
