\section{逆行列}\label{ux9006ux884cux5217}}

正方行列 \texttt{A} に対して

\[
A^{-1}A=AA^{-1}=I
\]

を満たす行列を逆行列と呼びます。

\hypertarget{ux9006ux884cux5217ux304cux5b58ux5728ux3059ux308bux3068ux306fux4f55ux304b}{%
\subsection{逆行列が存在するとは何か}\label{ux9006ux884cux5217ux304cux5b58ux5728ux3059ux308bux3068ux306fux4f55ux304b}}

\texttt{A}
が可逆であることは、線形写像が情報を一切失わないことを意味します。

同値な条件には

\begin{itemize}
\tightlist
\item
  \texttt{ker(A)=\{0\}}
\item
  \texttt{rank(A)=n}
\item
  列が一次独立
\item
  \texttt{det(A)≠0}
\item
  0 が固有値でない
\item
  最小特異値が 0 でない
\end{itemize}

などがあります。

\hypertarget{ux5b9fux52d9ux4e0aux306eux6ce8ux610f}{%
\subsection{実務上の注意}\label{ux5b9fux52d9ux4e0aux306eux6ce8ux610f}}

\texttt{Ax=b} を解くために明示的に \texttt{A\^{}\{-1\}}
を計算する必要は通常ありません。LU や QR
などの分解を用いる方が効率・数値安定性の面で優れています。
