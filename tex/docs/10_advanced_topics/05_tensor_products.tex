\hypertarget{ux30c6ux30f3ux30bdux30ebux7a4d}{%
\section{テンソル積}\label{ux30c6ux30f3ux30bdux30ebux7a4d}}

テンソル積 \texttt{V⊗W}
は、二つのベクトル空間からより大きな線形空間を構成する操作です。

有限次元では基底 \texttt{e\_i} と \texttt{f\_j} に対し

\[
e_i\otimes f_j
\]

が基底を作ります。

\hypertarget{ux5916ux7a4dux3068ux306eux63a5ux7d9a}{%
\subsection{外積との接続}\label{ux5916ux7a4dux3068ux306eux63a5ux7d9a}}

列ベクトル \texttt{u,v} に対する

\[
uv^\top
\]

は rank-1 行列であり、テンソル積的な構造を持ちます。

SVD

\[
A=\sum_i\sigma_i u_i v_i^\top
\]

は行列を rank-1 テンソルの和へ分解していると見ることもできます。
