\hypertarget{ux884cux5217ux95a2ux6570}{%
\section{行列関数}\label{ux884cux5217ux95a2ux6570}}

スカラー関数 \texttt{f(x)} を行列へ拡張したものを \texttt{f(A)}
と考えます。

\texttt{A=PΛP\^{}\{-1\}} と対角化できるなら

\[
f(A)=Pf(\Lambda)P^{-1}
\]

と定義できます。\texttt{f(Λ)} は各固有値に \texttt{f}
を適用した対角行列です。

\hypertarget{ux4f8b}{%
\subsection{例}\label{ux4f8b}}

\begin{itemize}
\tightlist
\item
  \texttt{A\^{}k}
\item
  \texttt{e\^{}A}
\item
  \texttt{sin\ A}
\item
  \texttt{log\ A}
\end{itemize}

などです。

\hypertarget{ux672cux8cea}{%
\subsection{本質}\label{ux672cux8cea}}

固有値分解が有用なのは、行列関数を「各固有方向に対するスカラー関数」へ還元できるからです。
