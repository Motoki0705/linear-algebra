\section{行列指数関数}\label{ux884cux5217ux6307ux6570ux95a2ux6570}}

行列指数関数は

\[
e^{At}=I+At+\frac{(At)^2}{2!}+\cdots
\]

で定義されます。

線形微分方程式

\[
\frac{dx}{dt}=Ax
\]

の解は

\[
x(t)=e^{At}x(0)
\]

です。

\texttt{A=PΛP\^{}\{-1\}} なら

\[
e^{At}=Pe^{\Lambda t}P^{-1}
\]

なので各固有方向は \texttt{e\^{}\{λ\_it\}} で成長または減衰します。

このため固有値の実部が力学系の安定性を決定します。
