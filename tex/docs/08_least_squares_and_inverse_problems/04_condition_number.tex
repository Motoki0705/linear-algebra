\hypertarget{ux6761ux4ef6ux6570}{%
\section{条件数}\label{ux6761ux4ef6ux6570}}

可逆行列に対する2-ノルム条件数は

\[
\boxed{\kappa_2(A)=\|A\|_2\|A^{-1}\|_2=\frac{\sigma_{\max}}{\sigma_{\min}}}
\]

です。

\hypertarget{ux5e7eux4f55ux5b66ux7684ux610fux5473}{%
\subsection{幾何学的意味}\label{ux5e7eux4f55ux5b66ux7684ux610fux5473}}

\texttt{A} は単位球を楕円体へ写します。最長半径が
\texttt{σ\_max}、最短半径が \texttt{σ\_min} です。

\texttt{σ\_min}
が非常に小さいと、ある方向がほとんど平らに潰れています。その出力から元の入力を復元するには
\texttt{1/σ\_min} 倍する必要があり、観測ノイズまで大きく増幅します。

\hypertarget{ux6761ux4ef6ux304cux60aaux3044ux3068ux306f}{%
\subsection{条件が悪いとは}\label{ux6761ux4ef6ux304cux60aaux3044ux3068ux306f}}

条件数が大きい問題は、アルゴリズムが悪い以前に「問題そのものが入力誤差に敏感」です。

数値線形代数では

\begin{itemize}
\tightlist
\item
  問題の conditioning
\item
  アルゴリズムの stability
\end{itemize}

を区別することが重要です。
