\hypertarget{ux4e00ux6b21ux7d50ux5408}{%
\section{一次結合}\label{ux4e00ux6b21ux7d50ux5408}}

ベクトル \texttt{v\_1,...,v\_k} に対して

\[
a_1v_1+\cdots+a_kv_k
\]

の形を一次結合と呼びます。

一次結合は、線形代数のほぼすべてを貫く基本操作です。

\hypertarget{ux306aux305cux91cdux8981ux306aux306eux304b}{%
\subsection{なぜ重要なのか}\label{ux306aux305cux91cdux8981ux306aux306eux304b}}

「あるベクトルを既知の方向の組合せとして表せるか」という問いは、

\[
Ax=b
\]

を解くことそのものです。\texttt{A} の列を \texttt{a\_1,...,a\_n}
とすると

\[
Ax=x_1a_1+\cdots+x_na_n
\]

だからです。

したがって連立方程式は、「\texttt{b} は \texttt{A}
の列ベクトルの一次結合で作れるか」と読み替えられます。

\hypertarget{ux91cdux8981ux306aux898bux65b9}{%
\subsection{重要な見方}\label{ux91cdux8981ux306aux898bux65b9}}

行列積 \texttt{Ax} を成分ごとの公式として覚えるより、\textbf{A
の列の一次結合}
と理解してください。この見方から列空間、ランク、解の存在条件が自然につながります。
