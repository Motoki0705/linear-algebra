\section{Chapter 01 ---
ベクトルと空間}\label{chapter-01-ux30d9ux30afux30c8ux30ebux3068ux7a7aux9593}}

この章の目的は、ベクトルを「数の並び」から解放することです。

\hypertarget{ux4e2dux5fc3ux3068ux306aux308bux8003ux3048}{%
\subsection{中心となる考え}\label{ux4e2dux5fc3ux3068ux306aux308bux8003ux3048}}

線形代数では、対象そのものよりも「その対象をどの方向の組合せとして表せるか」を考えます。

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{ベクトル}
\NormalTok{ ↓}
\NormalTok{一次結合}
\NormalTok{ ↓}
\NormalTok{span（作れる範囲）}
\NormalTok{ ↓}
\NormalTok{一次独立（冗長でない方向）}
\NormalTok{ ↓}
\NormalTok{基底（必要十分な方向の集合）}
\NormalTok{ ↓}
\NormalTok{次元（独立な自由度の数）}
\end{Highlighting}
\end{Shaded}

この流れは別々の用語集ではありません。すべて「空間を最小限の独立な方向で記述する」という一つの問題に答えています。

\hypertarget{ux6700ux3082ux91cdux8981ux306aux533aux5225}{%
\subsection{最も重要な区別}\label{ux6700ux3082ux91cdux8981ux306aux533aux5225}}

\textbf{ベクトルと座標は別物です。}

同じ矢印でも、基底を変えれば座標は変わります。例えば通常の基底では
\texttt{(1,1)} と表されるベクトルが、別の基底では \texttt{(√2,0)}
と表されるかもしれません。

この事実を受け入れると、後の対角化や SVD
の意味が見えます。それらは「線形変換が簡単に見える座標系を探す」方法だからです。

\hypertarget{ux5b66ux7fd2ux6642ux306bux8003ux3048ux308bux554fux3044}{%
\subsection{学習時に考える問い}\label{ux5b66ux7fd2ux6642ux306bux8003ux3048ux308bux554fux3044}}

\begin{itemize}
\tightlist
\item
  \texttt{span} はなぜ必ず部分空間になるのか。
\item
  一次従属なベクトルを基底から取り除いても span が変わらないのはなぜか。
\item
  \texttt{R\^{}1000}
  のデータでも本質的には10次元ということはあり得るか。
\item
  基底を変えても次元が変わらないのはなぜか。
\end{itemize}

\hypertarget{ux5178ux578bux7684ux306aux8aa4ux89e3}{%
\subsection{典型的な誤解}\label{ux5178ux578bux7684ux306aux8aa4ux89e3}}

「ベクトルの成分数 =
常に本質的な次元」ではありません。成分数は周囲の座標空間の次元であり、データ集合が張る部分空間の次元はもっと小さいことがあります。この差が
rank や PCA の出発点です。

\hypertarget{ux5230ux9054ux57faux6e96}{%
\subsection{到達基準}\label{ux5230ux9054ux57faux6e96}}

章末では、基底を「空間を一意に座標化する最小の独立方向集合」と説明できることを目指してください。
