\hypertarget{ux5bfeux79f0ux884cux5217}{%
\section{対称行列}\label{ux5bfeux79f0ux884cux5217}}

実行列 \texttt{A} が

\[
A^\top=A
\]

を満たすとき対称行列と呼びます。

対称行列は非常に特別で、

\begin{itemize}
\tightlist
\item
  固有値がすべて実数
\item
  異なる固有値の固有ベクトルは直交
\item
  正規直交固有基底を持つ
\end{itemize}

という性質があります。

したがって

\[
A=Q\Lambda Q^\top
\]

と分解できます。

\hypertarget{ux306aux305c-svd-ux306eux524dux306bux91cdux8981ux304b}{%
\subsection{なぜ SVD
の前に重要か}\label{ux306aux305c-svd-ux306eux524dux306bux91cdux8981ux304b}}

一般行列 \texttt{A} に対して \texttt{A\^{}TA} と \texttt{AA\^{}T}
は必ず対称行列です。SVD はこれらの固有値分解から構成できます。

つまり対称行列の理論は SVD の直接の土台です。
