\section{対角化}\label{ux5bfeux89d2ux5316}}

\texttt{A} が \texttt{n}
本の一次独立な固有ベクトルを持つとき、それらを列に並べた

\[
P=[v_1\ \cdots\ v_n]
\]

を使って

\[
\boxed{A=P\Lambda P^{-1}}
\]

と書けます。

\texttt{Λ} は固有値を並べた対角行列です。

\hypertarget{ux672cux8cea}{%
\subsection{本質}\label{ux672cux8cea}}

これは「固有ベクトルを基底として見ると、A は各座標を独立に λ\_i
倍するだけ」という意味です。

したがって

\[
A^k=P\Lambda^kP^{-1}
\]

となり、行列の累乗や線形力学系を理解しやすくなります。

対角化の中心思想は、\textbf{良い基底を選んで線形写像を単純化する}
ことです。
