\hypertarget{ux30e9ux30f3ux30af}{%
\section{ランク}\label{ux30e9ux30f3ux30af}}

行列 \texttt{A} のランクは像の次元です。

\[
\operatorname{rank}(A)=\dim\operatorname{Im}(A)
\]

\hypertarget{ux76f4ux611f}{%
\subsection{直感}\label{ux76f4ux611f}}

ランクは「この線形変換が何次元分の独立な情報を出力へ運べるか」を表します。

例えば \texttt{R\^{}3→R\^{}3}
の写像でも、すべての点を一つの平面へ潰すならランクは2です。一本の直線へ潰すならランクは1です。

\hypertarget{ux540cux5024ux306aux5b9aux7fa9}{%
\subsection{同値な定義}\label{ux540cux5024ux306aux5b9aux7fa9}}

ランクは

\begin{itemize}
\tightlist
\item
  独立な列の最大本数
\item
  独立な行の最大本数
\item
  pivot の数
\item
  非零特異値の数
\end{itemize}

のいずれでも求められます。

最後の見方から

\[
\operatorname{rank}(A)=\#\{\sigma_i>0\}
\]

となり、SVD と直接つながります。
