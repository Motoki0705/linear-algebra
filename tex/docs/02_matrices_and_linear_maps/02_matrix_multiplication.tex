\section{行列積}\label{ux884cux5217ux7a4d}}

\texttt{AB} は単なる計算規則ではなく、\textbf{線形写像の合成}
を表します。

\texttt{B:R\^{}n→R\^{}k}、\texttt{A:R\^{}k→R\^{}m} なら

\[
AB:R^n\to R^m
\]

であり、

\[
x\xrightarrow{B}Bx\xrightarrow{A}A(Bx)
\]

です。

したがって

\[
(AB)x=A(Bx)
\]

となります。

\hypertarget{ux306aux305cux4e00ux822cux306b-abba-ux306aux306eux304b}{%
\subsection{なぜ一般に AB≠BA
なのか}\label{ux306aux305cux4e00ux822cux306b-abba-ux306aux306eux304b}}

写像の順序を変えると結果が変わるからです。例えば「回転してから射影」と「射影してから回転」は通常同じ操作ではありません。

\hypertarget{svd-ux3068ux306eux63a5ux7d9a}{%
\subsection{SVD との接続}\label{svd-ux3068ux306eux63a5ux7d9a}}

\[
A=U\Sigma V^\top
\]

は、\texttt{V\^{}T}、\texttt{Σ}、\texttt{U}
という3つの写像の合成です。この意味を理解するためにも、行列積を写像の合成として捉えることが重要です。
