\hypertarget{ux6838ux3068ux50cf}{%
\section{核と像}\label{ux6838ux3068ux50cf}}

線形写像 \texttt{A:R\^{}n→R\^{}m} に対して

\[
\ker A=\{x\mid Ax=0\}
\]

を核、

\[
\operatorname{Im}A=\{Ax\mid x\in\mathbb{R}^n\}
\]

を像と呼びます。

\hypertarget{ux6838ux306eux610fux5473}{%
\subsection{核の意味}\label{ux6838ux306eux610fux5473}}

核は変換によって完全に消えてしまう入力方向です。\texttt{x\_1-x\_2∈ker(A)}
なら

\[
Ax_1=Ax_2
\]

なので、\texttt{A} はその二つの入力を区別できません。

\hypertarget{ux50cfux306eux610fux5473}{%
\subsection{像の意味}\label{ux50cfux306eux610fux5473}}

像は \texttt{A}
によって到達できる出力全体です。行列の場合、像は列空間と同じです。

\hypertarget{ux60c5ux5831ux3068ux3044ux3046ux8996ux70b9}{%
\subsection{情報という視点}\label{ux60c5ux5831ux3068ux3044ux3046ux8996ux70b9}}

核が大きいほど入力情報が失われます。像の次元がランクです。SVD
では零特異値に対応する右特異ベクトルが核を張ります。
