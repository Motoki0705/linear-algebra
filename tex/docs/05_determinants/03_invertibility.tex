\section{可逆性}\label{ux53efux9006ux6027}}

正方行列 \texttt{A∈R\^{}\{n×n\}} について、次はすべて同値です。

\begin{itemize}
\tightlist
\item
  \texttt{A} は可逆
\item
  \texttt{Ax=b} は任意の \texttt{b} に対して一意解を持つ
\item
  \texttt{ker(A)=\{0\}}
\item
  \texttt{rank(A)=n}
\item
  列ベクトルが一次独立
\item
  列ベクトルが \texttt{R\^{}n} を張る
\item
  \texttt{det(A)≠0}
\item
  0 は固有値でない
\item
  すべての特異値が正
\end{itemize}

これらは別々の暗記事項ではありません。

本質はただ一つ、\textbf{A がどの入力方向も潰していない}
という事実を、方程式・空間・行列式・固有値・SVD
という異なる言語で表現しているだけです。
