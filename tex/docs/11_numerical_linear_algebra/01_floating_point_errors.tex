\section{浮動小数点誤差}\label{ux6d6eux52d5ux5c0fux6570ux70b9ux8aa4ux5dee}}

コンピュータは実数を有限ビットで表すため、多くの実数を正確には保持できません。

計算は概念的に

\[
\operatorname{fl}(a\circ b)=(a\circ b)(1+\delta)
\]

のような小さな相対誤差を伴います。

\hypertarget{ux306aux305cux7ddaux5f62ux4ee3ux6570ux3067ux91cdux8981ux304b}{%
\subsection{なぜ線形代数で重要か}\label{ux306aux305cux7ddaux5f62ux4ee3ux6570ux3067ux91cdux8981ux304b}}

巨大な行列計算では小さな丸め誤差が蓄積します。また悪条件問題では、その小さな誤差が問題そのものによって増幅されます。

したがって理論上同値な式でも、コンピュータ上では同じ精度を持つとは限りません。
