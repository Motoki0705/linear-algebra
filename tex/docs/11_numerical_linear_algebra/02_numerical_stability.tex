\section{数値安定性}\label{ux6570ux5024ux5b89ux5b9aux6027}}

数値安定性は、丸め誤差を含む計算がどれだけ信頼できるかを扱います。

\hypertarget{conditioning-ux3068-stability}{%
\subsection{conditioning と
stability}\label{conditioning-ux3068-stability}}

\begin{itemize}
\tightlist
\item
  conditioning: 問題そのものが入力誤差にどれだけ敏感か
\item
  stability: アルゴリズムが追加誤差をどれだけ生むか
\end{itemize}

この二つを混同してはいけません。

例えば悪条件な \texttt{A} に対して正規方程式を使うと

\[
\kappa(A^TA)=\kappa(A)^2
\]

となり問題をさらに厳しくします。そのため最小二乗では QR や SVD
が好まれる場合があります。
