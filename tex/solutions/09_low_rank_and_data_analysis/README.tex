\subsection{1}\label{section}}

Eckart--Young--Mirsky 定理より

\[
\|A-A_2\|_F=\sqrt{1^2+0.1^2}=\sqrt{1.01}.
\]

\hypertarget{section-1}{%
\subsection{2}\label{section-1}}

全エネルギーは
\texttt{100+9+1+0.01=110.01}、上位2成分は109なので保持率は

\[
109/110.01\approx0.9908
\]

すなわち約99.1\%です。

\hypertarget{section-2}{%
\subsection{3}\label{section-2}}

\texttt{X\_c=UΣV\^{}T} なら

\[
C=\frac1{n-1}VΣ^2V^T.
\]

よって \texttt{V}
の列が共分散行列の固有ベクトル、すなわち主成分方向です。

\hypertarget{section-3}{%
\subsection{4}\label{section-3}}

全分散は固定なので、部分空間へ射影して保持する分散を最大化することは、直交補空間へ捨てる二乗距離を最小化することと等価です。SVD
の最良低ランク近似定理がこれを厳密に与えます。

\hypertarget{section-4}{%
\subsection{5}\label{section-4}}

\texttt{k} が小さすぎると本物の弱い構造まで消して bias
が増えます。大きすぎるとノイズ成分を残して variance が増えます。適切な
\texttt{k} は信号構造とノイズ強度に依存します。
