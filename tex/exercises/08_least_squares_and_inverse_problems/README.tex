\section{演習 08 ---
最小二乗と逆問題}\label{ux6f14ux7fd2-08-ux6700ux5c0fux4e8cux4e57ux3068ux9006ux554fux984c}}

\hypertarget{ux76f4ux7ddaux30d5ux30a3ux30c3ux30c6ux30a3ux30f3ux30b0}{%
\subsection{1.
直線フィッティング}\label{ux76f4ux7ddaux30d5ux30a3ux30c3ux30c6ux30a3ux30f3ux30b0}}

点 \texttt{(0,1),(1,2),(2,2)} に \texttt{y=ax+b}
を最小二乗で当てはめるための \texttt{A,x,b}
を構成し、正規方程式を解いてください。

\hypertarget{ux6b63ux898fux65b9ux7a0bux5f0f}{%
\subsection{2. 正規方程式}\label{ux6b63ux898fux65b9ux7a0bux5f0f}}

\texttt{\textbar{}\textbar{}Ax-b\textbar{}\textbar{}\^{}2} を微分して
\texttt{A\^{}TAx=A\^{}Tb} を導出してください。

\hypertarget{ux5c04ux5f71}{%
\subsection{3. 射影}\label{ux5c04ux5f71}}

full-column-rank \texttt{A} に対して

\[
P=A(A^TA)^{-1}A^T
\]

が列空間への直交射影であることを示してください。

\hypertarget{ux64ecux4f3cux9006}{%
\subsection{4. 擬似逆}\label{ux64ecux4f3cux9006}}

SVD から \texttt{A\^{}+=VΣ\^{}+U\^{}T} を構成し、可逆正方行列の場合に
\texttt{A\^{}+=A\^{}\{-1\}} となることを示してください。

\hypertarget{ux6761ux4ef6ux6570}{%
\subsection{5. 条件数}\label{ux6761ux4ef6ux6570}}

特異値が \texttt{10} と \texttt{10\^{}\{-4\}}
の行列の2-ノルム条件数を求め、その値が逆問題に何を意味するか説明してください。
