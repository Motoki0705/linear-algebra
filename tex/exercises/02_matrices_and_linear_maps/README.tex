\hypertarget{ux5217ux306eux4e00ux6b21ux7d50ux5408}{%
\subsection{1.
列の一次結合}\label{ux5217ux306eux4e00ux6b21ux7d50ux5408}}

\[
A=\begin{bmatrix}1&2\\3&4\\5&6\end{bmatrix},\quad x=\begin{bmatrix}2\\-1\end{bmatrix}
\]

について \texttt{Ax} を計算し、それを \texttt{A}
の列ベクトルの一次結合として説明してください。

\hypertarget{ux6838}{%
\subsection{2. 核}\label{ux6838}}

\[
A=\begin{bmatrix}1&2&3\\2&4&6\end{bmatrix}
\]

の核の基底と次元を求めてください。

\hypertarget{ux30e9ux30f3ux30af}{%
\subsection{3. ランク}\label{ux30e9ux30f3ux30af}}

上の \texttt{A} のランクを求め、rank-nullity theorem
が成立することを確認してください。

\hypertarget{ux5199ux50cfux306eux5408ux6210}{%
\subsection{4. 写像の合成}\label{ux5199ux50cfux306eux5408ux6210}}

\texttt{AB} が「B を先に、A
を後に作用させる」ことを式で説明してください。また一般に \texttt{AB≠BA}
となる理由を写像の観点から説明してください。

\hypertarget{ux60c5ux5831ux640dux5931}{%
\subsection{5. 情報損失}\label{ux60c5ux5831ux640dux5931}}

\texttt{ker(A)} が非自明なら、なぜ \texttt{A}
から入力を一意に復元できないのか証明してください。
