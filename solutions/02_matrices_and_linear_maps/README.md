# 解答 02 — 行列と線形写像

## 1

\[
Ax=2\begin{bmatrix}1\\3\\5\end{bmatrix}-\begin{bmatrix}2\\4\\6\end{bmatrix}
=\begin{bmatrix}0\\2\\4\end{bmatrix}.
\]

行列積は列の一次結合として理解できます。

## 2

方程式は `x+2y+3z=0` 一本だけです。

\[
x=-2y-3z
\]

なので

\[
(x,y,z)^T=y(-2,1,0)^T+z(-3,0,1)^T.
\]

核の次元は2です。

## 3

第2行は第1行の2倍なので rank は1です。入力次元3に対し

\[
\dim\ker A+\operatorname{rank}A=2+1=3
\]

で次元定理を満たします。

## 4

`(AB)x=A(Bx)` なので `B` が先です。写像の順序を交換すると中間状態が変わるため、一般には結果も変わります。

## 5

非零 `z∈ker(A)` を取ります。任意の `x` について

\[
A(x+z)=Ax+Az=Ax.
\]

異なる入力 `x` と `x+z` が同じ出力になるため、一意復元できません。
