# 解答 03 — 連立一次方程式

## 1

第2式から第1式の2倍を引くと `3z=2`、第3式に第1式を加えると `z=2` となり矛盾します。したがって解は存在しません。

この矛盾は augmented matrix に `0=非零` の行が現れることに対応します。

## 2

`A=[a_1 ... a_n]` なら

\[
Ax=x_1a_1+\cdots+x_na_n.
\]

よってある `x` で `Ax=b` が成立することは、`b` が列の一次結合で書けること、すなわち `b∈Col(A)` と同値です。

## 3

任意の解 `x` に対して `A(x-x_p)=b-b=0` なので `x-x_p∈ker(A)`。逆に `z∈ker(A)` なら `A(x_p+z)=b`。よって全解は `x_p+ker(A)` です。

## 4

核に非零 `z` があれば `x_p` と `x_p+z` が別解になるため一意ではありません。逆に核が `{0}` なら二解 `x_1,x_2` に対し `A(x_1-x_2)=0` から `x_1=x_2` です。

## 5

正方行列では full rank `n` なら nullity は0です。したがって写像は単射かつ全射となり、逆写像が存在します。これが逆行列です。
