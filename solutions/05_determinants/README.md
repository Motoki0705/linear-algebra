# 解答 05 — 行列式

## 1

`det(A)=6` なので面積は6倍です。

## 2

`det(A)=0` は線形変換が n 次元体積を0へ潰すことを意味します。したがって像の次元は n 未満で、列は n 本の独立方向を作れません。

## 3

`B` が体積を `det(B)` 倍し、その後 `A` が `det(A)` 倍するので、合成は積になります。符号も向きの反転回数として積で合成されます。

## 4

\[
\det A=\det U\det\Sigma\det V^T.
\]

直交行列の行列式は ±1 なので絶対値は1です。`det Σ=∏σ_i` だから結論が得られます。

## 5

同じではありません。例えば `A=10^{-6}I` は行列式が非常に小さい一方、条件数は1で完全に well-conditioned です。悪条件性は絶対的な体積ではなく、方向ごとの伸縮率の比 `σ_max/σ_min` に関係します。
